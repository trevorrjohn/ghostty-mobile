Support

Connection trouble, unexpected terminal behavior, or a question about your data? Start here.

Email support Report an issue

Before contacting support

Confirm the hostname, port, username, authentication method, and current network route. If a host key changed unexpectedly, do not approve it until you have verified the new fingerprint through a trusted channel.

Connection interruptions

A reconnect starts a new SSH transport and a new remote shell. Seance Shell does not claim that a disconnected remote process survived. Use tmux or screen on the remote host when process continuity matters.

Reporting a problem

Include your app version, Android or iOS version, device model, connection stage, and steps to reproduce. Do not send passwords, private keys, one-time codes, hostnames, terminal contents, remote paths, or screenshots containing secrets.

Android can export bounded diagnostics from Settings. Review the plaintext report before sharing it.

Security reports

Do not publish an unpatched vulnerability or sensitive host information in a public issue. Email ceo@founder.fail with a concise description and a safe way to reproduce the issue.

Documentation

Current capabilities and known limitations are maintained in the public product roadmap. The security model explains how credentials, host trust, remote effects, and local records are handled.
