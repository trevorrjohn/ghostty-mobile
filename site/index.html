Designed around reality

A terminal that understands where it runs.

Mobile networks change. Apps get suspended. Screens rotate. Ghostty Connect treats those constraints as product behavior, not edge cases.

01 / TRUST

Know the host.

Unknown and changed host keys stop the connection until you review the full fingerprint and make an explicit decision.

SHA256 vR7pK6Qx...2mAZ9d Review required
02 / NATIVE

At home on your device.

Platform-native rendering, secure storage, lifecycle handling, and input on Android and iOS. Shared behavior without a lowest-common-denominator UI.

Android iPhone iPad
03 / HONESTY

No pretend reconnects.

When a connection is lost, the app says so. A retry starts a new remote shell and never implies that an old process survived.

connected→offline→new shell

Core workflow

Everything between you and the prompt.

⌁

Saved hosts and identities

Organize remote hosts and import encrypted Ed25519 or RSA keys using platform-secure storage.

▦

A real terminal engine

Unicode, colors, cursor state, scrollback, selection, and mode-aware input through a pinned libghostty-vt revision.

⇥

Input for mobile work

Touch selection, configurable extra keys, external keyboards, safe paste, and correct remote PTY resizing.

◇

Bounded remote effects

Remote clipboard requests, notifications, links, and graphics are treated as untrusted input with explicit policy.
